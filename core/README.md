
Предположим, ваш файл называется `monitoring.jar`.

### Способ 1. PowerShell

Этот способ позволяет запустить процесс одной командой, скрыть окно и писать логи.

1.  Откройте папку с jar-файлом.
2.  Нажмите `Shift + ПКМ` (правая кнопка мыши) в пустом месте папки -> **"Открыть окно PowerShell здесь"**.
3.  Вставьте и выполните эту команду:

```powershell
Start-Process -FilePath "java" -ArgumentList "-jar", "monitoring.jar" -RedirectStandardOutput "app.log" -RedirectStandardError "app.log" -WindowStyle Hidden
```

**Что происходит:**
*   `-WindowStyle Hidden`: Черное окно консоли не появится.
*   `-RedirectStandardOutput "app.log"`: Весь ваш `FastLogger` будет писать в этот файл.
*   `2>&1` (Error redirection): Ошибки тоже пойдут в этот файл.

**Как остановить:**
Так как окна нет, закрыть его нельзя.
1.  Откройте Диспетчер задач (`Ctrl + Shift + Esc`).
2.  Перейдите во вкладку "Подробности" (Details).
3.  Найдите `java.exe` (или `javaw.exe`).
4.  Снимите задачу.

### Способ 2. VBScript (Для запуска двойным кликом)

Этот способ создает файл, по которому можно кликнуть мышкой, и программа запустится тихо.

**Шаг 1. Создайте `run.bat`**
Создайте текстовый файл, переименуйте в `run.bat`, внутри напишите:
```bat
java -jar monitoring.jar > app.log 2>&1
```

**Шаг 2. Создайте `start.vbs`**
Создайте файл `start.vbs` рядом, внутри напишите:
```vbscript
Set WshShell = CreateObject("WScript.Shell") 
WshShell.Run chr(34) & "run.bat" & chr(34), 0
Set WshShell = Nothing
```
*(Цифра `0` в конце означает "Скрыть окно")*

**Запуск:** Просто кликните дважды по `start.vbs`. Появится файл `app.log`, программа работает.

### Способ 3. Использование `javaw` (Без батников)

В Java есть специальная версия exe-файла — `javaw.exe` (Java Windowless). Она создана специально для запуска без консоли.

Однако, `javaw` по умолчанию **проглатывает** логи, если их не перенаправить.

Создайте ярлык или батник `start.bat`:
```bat
start javaw -jar monitoring.jar > app.log 2>&1
```
*   `start` — запускает и отпускает консоль.
*   `javaw` — не создает окно консоли для Java.

### Способ 4. Планировщик заданий (Чтобы запускалось само при рестарте)

Это самый надежный вариант для "сервера" на Windows.

1.  Нажмите `Win + R`, введите `taskschd.msc`.
2.  **Создать простую задачу (Create Basic Task)**.
3.  Имя: `MonitoringService`.
4.  Триггер: **При запуске компьютера** (When the computer starts).
5.  Действие: **Запустить программу**.
6.  Программа/скрипт: Выберите ваш `run.bat` (из Способа 2).
    *   *Совет:* В поле "Начать в (рабочая папка)" укажите путь к папке с jar, иначе логи могут улететь в `System32`.
7.  В свойствах задачи поставьте галочку **"Скрытая задача"** (Hidden).

Теперь бот будет вставать сам вместе с Windows.

### Как смотреть логи в реальном времени (аналог `tail -f`)

В Windows нет команды `tail`, но в PowerShell есть аналог.
Откройте PowerShell в папке с логами и пишите:

```powershell
Get-Content app.log -Wait
```
Он будет выводить новые строки по мере их появления.
