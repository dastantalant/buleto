## StopConditionConfig — Parameters

| Type    | Name                    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Example                                                                                                                                                                                                                        |
| ------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Integer | stopLossPercentage      | Stop Loss (Ограничение убытка) в процентах от начального баланса. Если текущий баланс упадет ниже этого уровня относительно старта, игра остановится.                                                                                                                                                                                                                                                                                                                                                                  | Стартовый баланс 1000, stopLossPercentage = 20. Условие сработает, если баланс станет <= 800 (1000 - 20%).                                                                                                                     |
| Integer | takeProfitPercentage    | Take Profit (Фиксация прибыли) в процентах от начального баланса. Если текущий баланс вырастет выше этого уровня относительно старта, игра остановится.                                                                                                                                                                                                                                                                                                                                                                | Стартовый баланс 1000, takeProfitPercentage = 50. Условие сработает, если баланс станет >= 1500 (1000 + 50%).                                                                                                                  |
| Integer | trailingStopPercentage  | Trailing Stop (Скользящий стоп) в процентах от пикового баланса. Фиксирует прибыль. Если баланс упадет на указанный процент от максимально достигнутого за время игры значения, стратегия остановится.                                                                                                                                                                                                                                                                                                                 | Баланс поднялся до 2000 (пик). trailingStopPercentage = 10. Условие сработает, если баланс откатится до 1800 (2000 - 10%).                                                                                                     |
| Integer | maxDrawdownPercentage   | Максимальная допустимая просадка (Max Drawdown) в процентах. Это условие останавливает стратегию, если текущий баланс снизился относительно максимального значения (Peak Balance), достигнутого за всё время игры, более чем на указанный процент. Это механизм защиты накопленной прибыли. В отличие от stopLossPercentage (который считает от стартового баланса), этот параметр динамически отслеживает вашу "вершину". Формула срабатывания: (Пиковый_Баланс - Текущий_Баланс) >= (Пиковый_Баланс * Процент / 100) | Старт: 1000$. maxDrawdownPercentage = 25%. Баланс растет: 1200... 1500... 2000$. Допустимая просадка: 25% от 2000$ = 500$. Порог остановки: 2000$ - 500$ = 1500$. Если баланс упадет до 1500$ или ниже, стратегия остановится. |
| Integer | maxWinStreak            | Максимальная серия побед (Win Streak). Остановка после указанного количества выигранных раундов подряд. Полезно для стратегий "Hit and Run" (забрал и ушел).                                                                                                                                                                                                                                                                                                                                                           | maxWinStreak = 5. Победа → Победа → Победа → Победа → Победа → СТОП.                                                                                                                                                           |
| Integer | maxLossStreak           | Максимальная серия поражений (Loss Streak). Остановка после указанного количества проигранных раундов подряд. Предохранитель для мартингейл-подобных стратегий.                                                                                                                                                                                                                                                                                                                                                        | maxLossStreak = 6. Шесть поражений подряд вызовут остановку.                                                                                                                                                                   |
| Long    | maxRounds               | Лимит количества раундов. Жесткое ограничение на длительность игровой сессии.                                                                                                                                                                                                                                                                                                                                                                                                                                          | maxRounds = 1000. После 1000-го спина игра завершится независимо от результата.                                                                                                                                                |
| Double  | maxBetBalancePercentage | Максимальный риск на ставку (в долях от баланса). Останавливает стратегию, если она пытается сделать ставку, размер которой превышает указанную долю от текущего баланса. Защита от "слива" одной ставкой.                                                                                                                                                                                                                                                                                                             | maxBetBalancePercentage = 0.10 (10%). Баланс 5000. Стратегия хочет поставить 600. 600/5000 = 0.12 (12%). Так как 12% > 10%, игра будет остановлена перед этой ставкой.                                                         |
| Integer | stagnationWindow        | Окно стагнации (количество раундов). Остановка, если баланс не изменяется в течение указанного числа раундов (например, стратегия перестала делать ставки из-за внутренних фильтров).                                                                                                                                                                                                                                                                                                                                  | stagnationWindow = 50. Если 50 раундов подряд баланс один и тот же → СТОП.                                                                                                                                                     |
| Double  | minWinRateThreshold     | Минимальный порог Винрейта (Win Rate). Значение от 0.0 до 1.0. Если процент побед падает ниже этого уровня, игра останавливается.                                                                                                                                                                                                                                                                                                                                                                                      | minWinRateThreshold = 0.45 (45%).                                                                                                                                                                                              |
| Long    | minRoundsForWinRate     | Период "разогрева" для проверки Винрейта. Количество раундов, в течение которых проверка minWinRateThreshold игнорируется. Позволяет стратегии набрать статистику, чтобы не остановиться после первых пары неудач.                                                                                                                                                                                                                                                                                                     | minRoundsForWinRate = 100. Проверка на низкий винрейт начнется только со 101-го раунда.                                                                                                                                        |
