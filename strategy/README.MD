# 📊 Анализ результатов симуляции

Симулятор генерирует два типа CSV-отчетов:
1.  **`_FULL_RANKING.csv`** (через `FullCsvLogger`) — итоговая таблица рейтинга. Одна строка = одна стратегия.
2.  **`[StrategyName].csv`** (через `CsvLogger`) — детальная история каждого раунда для конкретной стратегии.

Ниже приведено описание полей и рекомендации по их анализу.

## 🏆 1. Итоговый рейтинг (`FullCsvLogger`)

Этот файл используется для сравнения эффективности стратегий между собой.

`Strategy;Rounds;StartBal;EndBal;NetProfit;ROI%;MaxDD%;WinRate%;PF;Won;Lost;Wagered;Payout;Status`

| Поле | Описание | 💡 Как анализировать |
| :--- | :--- | :--- |
| **Strategy** | Название стратегии. | Идентификатор алгоритма. |
| **Rounds** | Количество сыгранных раундов. | **Выживаемость.** Если число меньше `MaxRounds` из конфига, значит стратегия "слила" депозит или сработал Stop-Loss раньше времени. |
| **StartBal** | Стартовый баланс. | Точка отсчета. |
| **EndBal** | Конечный баланс. | Итоговая сумма на счету. |
| **NetProfit** | Чистая прибыль (`EndBal - StartBal`). | Абсолютный результат в деньгах. Может быть отрицательным. |
| **ROI%** | Return on Investment (Рентабельность). | **Эффективность.** Показывает процент заработка от стартового капитала. <br>✅ *Хорошо:* > 10-20% при низкой просадке. |
| **MaxDD%** | **Max Drawdown** (Максимальная просадка). | **Риск.** Показывает максимальное падение баланса относительно исторического пика в процентах. <br>❌ *Опасно:* > 50%. Это значит, что в моменте вы теряли половину депозита. Стратегия с ROI 100% и MaxDD 99% — это просто удача, а не стратегия. |
| **WinRate%** | Процент выигранных раундов. | **Характер стратегии.** <br>🔸 *Низкий (2-10%):* Ставки на числа (Straight Up). Нужен большой запас прочности.<br>🔸 *Высокий (48%+):* Равные шансы (Red/Black).<br>🔸 *Аномально высокий (90%+):* Скорее всего, Мартингейл. Ожидайте резкого краха в будущем. |
| **PF** | **Profit Factor**. Отношение выплат к сумме ставок (`Payout / Wagered`). | **Святой Грааль.** Ключевой показатель качества.<br>🟢 **PF > 1.0**: Стратегия прибыльна (математическое ожидание положительное на дистанции).<br>🔴 **PF < 1.0**: Стратегия убыточна.<br>⚪ **PF = 1.0**: Игра "в ноль". |
| **Won** | Кол-во выигранных раундов. | Абсолютный счетчик побед. |
| **Lost** | Кол-во проигранных раундов. | Абсолютный счетчик поражений. |
| **Wagered** | Общая сумма сделанных ставок (Оборот). | Показывает активность стратегии. Высокий оборот при низкой прибыли означает, что вы "кормите" казино (зеро съедает прибыль). |
| **Payout** | Общая сумма выплат от казино. | Сколько денег вернулось обратно. |
| **Status** | Причина остановки. | `FINISHED` (прошла все раунды), `STOPPED` (сработал стоп-лосс, обнулился баланс или достигнут тейк-профит). |

## 📈 2. Детальная история (`CsvLogger`)

Этот файл создается для каждой стратегии отдельно и позволяет построить график баланса или найти ошибку в логике ставок.

`Strategy;Round;Spot;Balance;NetProfit;RoundPnL;BetAmt;ROI%;MaxDD%;WinRate%;PF;Won;Lost;Wagered;Payout;Status;Bets`

| Поле | Описание | 💡 На что смотреть |
| :--- | :--- | :--- |
| **Round** | Номер текущего спина. | Ось X для графиков. |
| **Spot** | Выпавшее число (напр. `32` или `0`). | Позволяет проверить, почему ставка сыграла или проиграла. |
| **Balance** | Текущий баланс. | Ось Y для графика баланса. Ищите резкие падения ("кочерга") вниз. |
| **RoundPnL** | Profit/Loss за **этот** раунд. | `+` выиграли, `-` проиграли. Показывает волатильность стратегии. |
| **BetAmt** | Сумма ставок в этом раунде. | **Контроль Мартингейла.** Если это число растет экспоненциально (1, 2, 4, 8, 16...), стратегия агрессивная. |
| **MaxDD%** | Максимальная просадка (накопленная). | Растет только если текущая просадка превышает исторический максимум. |
| **PF** | Profit Factor (накопленный). | В начале игры он будет скакать. Смотреть нужно на значение после 100-200 раундов, когда оно стабилизируется. |
| **Bets** | Список сделанных ставок (напр. `RED:10`). | **Отладка.** Проверьте, ставит ли бот туда, куда вы задумывали. Пример: `RED:100 SPLIT_0_2:50`. |

## 🔍 Пример анализа стратегий

**Сценарий А: Агрессивный Мартингейл**
*   **ROI%:** +50% (Выглядит круто)
*   **MaxDD%:** 85% (Катастрофа)
*   **Status:** STOPPED (Баланс упал в ноль на 300-м раунде)
*   *Вердикт:* Стратегия сольет депозит, просто повезло продержаться долго.

**Сценарий Б: Стабильный Флэт (Flat Betting)**
*   **ROI%:** -2.7% (Медленный слив)
*   **MaxDD%:** 5% (Низкий риск)
*   **PF:** 0.97 (Математическое ожидание рулетки)
*   *Вердикт:* Классическая игра с отрицательным матожиданием (House Edge).

**Сценарий В: "Святой Грааль" (Ошибка в коде или удачная подгонка)**
*   **ROI%:** +150%
*   **MaxDD%:** 10%
*   **PF:** 1.25
*   *Вердикт:* Либо найден паттерн в ГПСЧ (генераторе чисел), либо ошибка в логике выплат (симулятор считает выплату больше, чем надо). Требует детальной проверки через `CsvLogger`.
